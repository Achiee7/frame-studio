# Contributing

Use Node.js 22.18 or newer and `npm ci`. Keep changes scoped, run `npm test` and `npm run build`, and include a concrete reproduction and an independent check for any structural-solver change. Keep the static build free of sign-in, backend and telemetry dependencies. Do not commit user project files, credentials, generated source archives or `dist/`.

Contributions are distributed under GPL-3.0-only, the same license as the project.
